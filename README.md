# رحلة الحروف 🔤

مشروع تعليمي بسيط لإنشاء رحلة حروف باستخدام QR وGitHub Pages.

## الملفات
- `index.html` الصفحة الرئيسية ومحطات الحروف.
- `style.css` التصميم.
- `app.js` الحروف والأسئلة ونظام التقدم.
- `qr.html` مولّد أكواد QR.

## النشر على GitHub Pages
1. ارفع الملفات الأربعة إلى المستودع.
2. من GitHub افتح: Settings → Pages.
3. اختر النشر من `main` ومن المجلد `/ (root)`.
4. بعد ظهور رابط الموقع، افتح `qr.html`.
5. أدخل رابط الموقع الأساسي، مثل:
   `https://USERNAME.github.io/REPOSITORY/`
6. أنشئ أكواد QR.
7. اطبع كل QR وضعه في محطة الحرف المناسبة.

> مولّد QR يستخدم خدمة QR خارجية عبر الإنترنت لإنشاء صور الرموز. يمكن لاحقاً استبدالها بمكتبة محلية إذا أردت المشروع يعمل بدون خدمة خارجية.
